# Tools

PC-side scripts that support development (not flashed to the robot), e.g.:

- servo calibration helpers
- gait trajectory plotting / simulation
- ball-detection experiments

| Tool | What it does |
|------|--------------|
| [`tof-grid/`](tof-grid/) | Live 8×8 grid view of a VL53L5CX ToF sensor on an ESP32-S3 |

Give each tool a short header comment explaining what it does and how to run
it, and list any Python dependencies in a `requirements.txt` here.
