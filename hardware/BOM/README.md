# Bill of Materials

[`BOM.csv`](BOM.csv) is the master list. Open it in Excel, LibreOffice or
Google Sheets, but **save it back as CSV** (UTF-8, comma-separated) so changes
show up in git diffs.

**Status** column: `Proposed` → `Ordered` → `Received` → `Installed`
(or `TBD` / `Optional`).

Prices may be in THB or JPY depending on where the part is bought — fill in the
`Currency` column.
